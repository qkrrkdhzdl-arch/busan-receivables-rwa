검수 끝난 외상값을 토큰으로

감천항·자갈치 냉동창고에서 검수와 세금계산서까지 끝났지만 60~90일 뒤에 입금되는 수산물 외상매출채권을, 신탁·SPV 이전과 솔라나 SPL 토큰 발행으로 유동화합니다. 재고나 어획물이 아니라 만기와 채무자가 증빙으로 특정된 확정 채권만 대상입니다.

샘플 데이터 3건 · 실제 유통사 데이터 아님 파이썬 데모와 같은 판정 규칙 (체크 12항목) 금액·연체율은 가정값 설치 없이 클릭으로 확인

네 단계 — 확정 → 격리 → 발행 → 상환

증빙이 없는 것이 문제가 아니라, 증빙을 금융이 읽을 수 있는 형태로 확정해 주는 장치가 없는 것이 문제입니다.

① 확정

4종 증빙 대조

주문서·출고 전표·검수 확인·세금계산서를 대조해 금액·만기·채무자·품목을 확정. 하나라도 어긋나면 발행 보류.

② 격리

신탁·SPV 이전

채무자 양도 통지·승낙으로 민법 제450조 대항요건 확보. 수납은 분리계좌로만.

③ 발행

솔라나 SPL

채권 해시·만기·유보율·워터폴을 온체인에 기록. 원본 문서·거래처 정보는 오프체인.

④ 상환

워터폴 분배

만기 회수액을 비용 → 투자자 원금 → 이자 → 유통사 순서로 분배. 손실은 유보금이 먼저 흡수.

데모 ① 증빙 4종 대조 — 확정 / 보류 판정

아래 표의 행을 누르면 12개 체크 항목의 판정 근거가 열립니다. 파이썬 demo/evidence_match.py와 같은 규칙·같은 채권 해시를 계산합니다.

정직하게 밝히는 것

  • 이 페이지는 샘플 JSON 3건으로 동작하는 해커톤 데모입니다. 실제 유통사·창고 데이터가 아니며, 문서 OCR·AI 판독은 범위 밖(추출이 끝난 구조화 데이터의 검증 로직만)입니다.
  • 유보금·조달비용·연체율은 가정값입니다. 표본 채권 상환 이력으로 검증하기 전에는 확정 수치가 아닙니다.
  • 채권의 증권성, 발행 주체 적격성, 투자자 청약 요건은 법률검토 전 확정할 수 없습니다. 이 설계는 그 검토와 혁신금융서비스 규제샌드박스 신청을 전제로 합니다.
  • 창고 2곳·유통사 5곳 참여는 협의 전 가정이며, 해커톤 기간에 참여 확인서로 대체합니다.
