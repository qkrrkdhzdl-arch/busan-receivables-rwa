# 검수 끝난 외상값을 토큰으로 — 부산 수산물 납품확정 채권 RWA

부산 블록체인 해커톤 2026 · **TRACK 01. Busan RWA** 출품작입니다.

감천항·자갈치 냉동창고에서 **검수와 세금계산서까지 끝났지만 60~90일 뒤에 입금되는** 수산물 외상매출채권을, 신탁·SPV 이전과 솔라나(Solana) 토큰 발행으로 유동화하는 서비스입니다. 재고나 어획물이 아니라, **만기와 채무자가 증빙으로 특정된 확정 채권**만 토큰화합니다.

## 문제

부산 수산물 유통은 `출고 → 검수 → 세금계산서 → 60~90일 후 입금` 구조입니다. 이 기간 중소 유통사는 다음 매입을 위한 현금이 없어 자기자금과 고금리 단기 차입에 의존합니다.

- 은행은 수산물 재고를 담보로 잡지 않습니다(등급·선도·시세 변동).
- 외상매출채권 담보대출은 거래처 한도 산정과 **채권 확인서 징구** 단계에서 막힙니다.
- 반면 주문서·출고 전표·검수 확인·세금계산서 **네 가지 증빙은 이미 시스템에 남아 있습니다.**

문제는 증빙이 없다는 것이 아니라, 증빙을 금융이 읽을 수 있는 형태로 확정해 주는 장치가 없다는 것입니다.

## 해결 — 4단계

| 단계 | 하는 일 | 산출물 |
| --- | --- | --- |
| ① 확정 | 주문·출고·검수·세금계산서 4종을 대조해 금액·만기·채무자·품목을 확정. 하나라도 어긋나면 발행 보류 | 채권 확정서, 대조 로그 |
| ② 격리 | 확정 채권을 신탁 또는 SPV로 이전. 채무자 양도 통지·승낙으로 민법 제450조 대항요건 확보. 수납은 분리계좌로만 | 양도대장, 통지·승낙서, 수납위임 |
| ③ 발행 | 확정 채권을 기초로 솔라나 SPL 토큰 발행. 채권 해시·만기·유보율·워터폴이 온체인에 기록, 원본 문서는 오프체인 | 토큰, 온체인 이력 |
| ④ 상환 | 만기(60~90일) 회수액을 워터폴 순서로 분배 | 정산 리포트 |

**토큰화하지 않는 것**: 재고, 어획물, 위탁판매 물량, 미확정 견적, 90일 초과 채권, 특수관계 거래. 소유권·환가가치·회수 가능성을 담보할 수 없기 때문입니다.

## 웹 데모

설치 없이 클릭으로 확인: **https://qkrrkdhzdl-arch.github.io/busan-receivables-rwa/**

## 실행

Python 3.10 이상, 표준 라이브러리만 사용합니다.

```bash
python3 demo/evidence_match.py
python3 demo/waterfall.py

# 웹 데모(docs/index.html) 재생성 — 파이썬 판정 결과를 그대로 페이지에 심습니다
python3 site/build_site.py
```

출력 예시:

```
케이스       판정      채권 해시
------------------------------------------------------------------------------
CASE-001  PASS    0xd5cff27a912cbbc2de84be21…
CASE-002  HOLD    0xa28c39bf9f2e5a52b96952b0…
    └ 수량 일치: 검수 288 / 세금계산서 300 / 출고 300 (사유: 해동 감모 12박스, 감모분 제외 발행 요청)
    └ 채무자 승낙: 승낙 회수 여부
CASE-003  PASS    0xcede6e174138dbedd9848f0e…
------------------------------------------------------------------------------
확정 2건 / 보류 1건 (총 3건)
```

`evidence_match.py`가 검사하는 항목: ① 거래처 사업자번호 일치 ② 품목 일치 ③ 수량 일치(검수 기준, 감모 사유가 확인되지 않으면 보류) ④ 수량×단가=합계 ⑤ 검수일 ≤ 세금계산서 발행일 ⑥ 만기 60~90일 ⑦ 동일 채권 해시 이중 발행 차단 ⑧ 채무자 양도 통지 ⑨ 채무자 승낙 ⑩ 분리계좌 수납위임 ⑪ 특수관계 거래 아님 ⑫ 위탁판매 아님.

`waterfall.py`는 채권 1억 원·75일·유보금 10%·투자자 연 5%·비용 0.8% 가정에서 정산 순서(비용 → 투자자 원금 → 이자 → 유통사 정산)와 연체율 0.5%·1.5%·3.0%·12% 시나리오를 계산합니다. **투자자 손실은 유보금 10%를 넘는 연체부터 발생**하며, 이 경계는 유보금 비율을 바꾸면 함께 움직입니다.

## 온체인 설계

- **온체인**: SPL 토큰 발행·전송, 채권 해시, 만기, 유보율, 워터폴 파라미터, 상환 이벤트 로그.
- **오프체인**: 원본 증빙, 양도대장, 채무자 통지·승낙 관리, 정산 대사.
- **개인정보·거래처 상호는 온체인에 올리지 않습니다.** 채권 해시로만 연결합니다.

## 가정과 한계 (정직하게)

- 이 저장소는 **해커톤 제출용 데모**입니다. 실제 유통사·창고 데이터가 아니라 샘플 JSON이며, 문서 OCR·AI 판독은 범위 밖입니다(추출이 끝난 구조화 데이터의 검증 로직만 구현).
- 유보금·조달비용·연체율은 **가정값**입니다. 표본 채권 상환 이력으로 검증하기 전에는 확정 수치가 아닙니다.
- 채권의 증권성, 발행 주체 적격성, 투자자 청약 요건은 **법률검토 전 확정할 수 없습니다.** 이 설계는 그 검토(및 혁신금융서비스 규제샌드박스 신청)를 전제로 합니다.
- 창고 2곳·유통사 5곳 참여는 협의 전 가정이며, 해커톤 기간에 참여 확인서로 대체합니다.

## 확장 경로

수산물(감천항·자갈치) → 농산물·축산 콜드체인 → 부산항 물류(창고·운송) → 선박 기자재. 같은 증빙 대조 엔진을 그대로 씁니다.
